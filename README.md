Árvore Binária de Busca em C

Sobre o Projeto
Este projeto implementa uma Árvore Binária de Busca (BST - Binary Search Tree) em linguagem C.
A aplicação permite inserir elementos, realizar buscas, visualizar os dados em ordem crescente, exibir a estrutura da árvore e reinicializar toda a árvore através de um menu interativo executado no terminal.
O objetivo do projeto é demonstrar conceitos fundamentais de Estruturas de Dados, Ponteiros, Recursão e Gerenciamento Dinâmico de Memória.


Funcionalidades

Inserção de elementos
Busca de valores
Percurso em ordem (In-Order)
Exibição visual da árvore
Liberação de memória
Reinicialização da árvore
Menu interativo

Tecnologias Utilizadas

Linguagem C
Biblioteca stdio.h
Biblioteca stdlib.h

Como Compilar
Linux / Mac
gcc arvore.c -o arvore
./arvore

Windows (MinGW)
gcc arvore.c -o arvore.exe
arvore.exe


Exemplo de Uso
Inserindo os valores:
50
30
70
20
40


Estrutura resultante:
        50
       /  \
     30    70
    / \
  20  40


Exibição em ordem:
20,30,40,50,70
